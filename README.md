# VGLive MyMusic

A modern music streaming web application built with:

- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 Audio API
- LocalStorage
- GitHub Pages

## Features

### Current

- Modern responsive music UI
- Home page
- Search
- Music cards
- Album cards
- Artist cards
- Audio player
- Play / pause
- Previous / next
- Seek bar
- Volume control
- Shuffle
- Repeat
- Like songs
- Recently played
- Dark / light theme
- Mobile responsive layout

### Planned

- Real music API
- Song search
- Album pages
- Artist pages
- Playlists
- Queue
- Full-screen player
- Media Session API
- PWA
- Offline application shell
